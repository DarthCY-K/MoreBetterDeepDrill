# RimWorld 1.7 validation

Initial development build: 2026-11-15.

## Reference environment

- Local game: RimWorld 1.7.5005 rev1082.
- Local `Assembly-CSharp.dll` assembly identity: 1.7.9810.32479.
- Runtime: .NET 10, using the game's root-level assemblies and UnityStubs.
- Harmony: installed Workshop mod's `1.7/Assemblies/0Harmony.dll`.
- Rimsage MCP: connection and queries work, but its indexed `Source/Properties/AssemblyInfo.cs` reports 1.6.9655.19392. Treat this index as 1.6 reference material until it is reindexed for 1.7.

## Completed checks

- Release build against the local 1.7 assemblies: zero warnings and errors.
- Loaded all 40 mod types under .NET 10 and resolved all 338 compiled member references against the installed dependencies.
- Verified all five Harmony patch targets resolve uniquely, including named arguments and injected `DeepResourceGrid.map` fields.
- Parsed every packaged 1.7 XML file and resolved the Def types, top-level Def fields, comp classes, job drivers, work giver, graphics class, and place workers against the mod and game assemblies.
- Verified that the 1.7 load folders exist and load only the 1.7 core DLL. The reusable `Source/1.7/CompatibilityCheck` console project runs these static checks against the packaged DLL; see the README for its command.

These checks establish compilation and static API compatibility. They do not exercise Harmony detours, the game's Def loader, rendering, or gameplay.

## Gameplay validation

On 2026-11-15, the maintainer reported that in-game testing found no issues and approved pushing the 1.7 update to GitHub. The individual scenarios covered were not specified.

The following checklist is retained for future regression testing:

- Load the mod with Harmony on 1.7; inspect the startup log for XML, translation, and patch errors.
- Build each drill and open the settings, resource selection menu, placement overlay, and inspection panel.
- Operate a ranged drill in normal and targeted modes; verify deposit depletion, exhaustion notification, and stone fallback.
- Operate a large drill with multiple colonists; verify reachability, reservations, and the drill power limit.
- Operate an archotech drill and verify the selected resource and configured yield.
- Cut and restore power; block and unblock output cells; verify work stops and pending output resumes without loss.
- Save and reload while drilling and while output is blocked; uninstall and reinstall a drill.
- Verify insect infestation settings and mech operator settings, with the relevant DLC available.

The existing 1.5 and 1.6 source and package files remain version-specific. No Project RimFactory extension is enabled for 1.7.
